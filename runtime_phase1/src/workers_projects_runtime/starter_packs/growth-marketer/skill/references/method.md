## Calculation contract

data.csv contains one row per period/channel with declared spend, visits, leads, qualified_leads, customers and attributed revenue. Counts must be integer, nonnegative and reconcile down the funnel. Currency/period must match plan.json. The explicit mutually_exclusive attribution assumption permits comparisons; reject aggregation when attribution is unknown. Zero denominators are unknown/null, never fabricated0. Revenue/spend is a descriptive ratio, not a causal marketing return or guaranteed next-quarter result.

Inputs and this aid are intentionally bounded. Do not apply a demonstrator to a different method merely because it runs. Public third-party sources are optional, pinned references, not automatically connected tools or proof of equivalence.
