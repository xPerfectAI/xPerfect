`demo/` holds a synthetic meaningful job, company onboarding material, expected numerical/quality checks and an intentionally bad input. It does not replace professional judgment, certify outputs or silently install tools.

External references are pinned in template.json. Selected licensed native Skills, when declared in template.json, include their exact source revision, license and explicit curation changes. No proprietary standards are bundled; no external connector is automatically installed or authorized. Native/community packages retain their own dependency, license, service and authorization requirements.
