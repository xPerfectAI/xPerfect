# xPerfect: References

The product uses the native capabilities and public interfaces of its supported harnesses.
Consult the current provider documentation when configuring a connection:

- [Codex CLI](https://developers.openai.com/codex/cli/)
- [Claude Code](https://code.claude.com/docs/en/setup)
- [Grok Build](https://github.com/xai-org/grok-build)
- [Model Context Protocol](https://modelcontextprotocol.io/specification/)

Supported routes and their current limits are listed in the [capability guide](capability-matrix.md).
